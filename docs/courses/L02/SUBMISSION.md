# L02 提交索引填写提示

沿[实践手册](实践操作手册.md)完成七步后，用下面字段核对自己的 `lesson-02-submission/记录.md`。其余四份原始材料继续作为依据，不要求重复填写新报告。

- 实际练习仓库、课程编号、日期和规则版本：
- 当前完成到哪一步；待确认／未验证项：

| 手册步骤 | 原有材料 | 索引时核对什么 |
|---|---|---|
| 1～2 | `记录.md` | 实际目录、规则首次判断、来源与本人选择 |
| 1 | `agents-before.md` | 修改前根目录 AGENTS 原文 |
| 3 | `N0.md` | 同一请求、实际新任务、原始回答与规则加载依据 |
| 4 | `agents-after.md` | 最小规则补丁及实际依据，不含临时任务状态 |
| 5 | `N1-and-boundary.md` | 全新任务的同一请求、N1 原文、越界与合法维护对照 |
| 6～7 | `记录.md` | 真实程序检查、退出码、失败、反馈、修订与迁移 |

## 本人的结论

- 一条规则保护了什么职责；亲自核对哪处实现／合同：
- N0 与 N1 哪些条件相同、哪些不同；是否观察到效果：
- 规则读取、越界纠正、合法维护、程序检查各支持什么结论：
- 未观察到改善时的说明；发生失败后怎样修订并重验：
- 同伴真实反馈及本人处理；无同伴写待互评：
- 迁移到采购审批时，需要重新确认什么：
- 当前接受／待修订／证据不足的理由、依据和剩余风险：

自然语言回答不伪造退出码，程序结果按实际命令记录。FlowERP 本讲未开发，不能填写业务交付通过。
