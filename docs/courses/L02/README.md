# L02｜把仓库规则写进 `AGENTS.md`

沿用 L01 的同一个练习仓库，固化工作台协作规则；本讲不改业务功能。

只按一条路线学习：先读讲义理解本讲问题，再在手册中逐步操作，最后用提交索引核对自己的证据。

| 主文件 | 何时使用 |
|---|---|
| [辅导资料](辅导资料.md) | 理解案例、机制和设计判断；原理随实践回查 |
| [实践操作手册](实践操作手册.md) | 按步骤完成目标、操作、结果与排错；提示词就在首次使用步骤内 |
| [SUBMISSION 提交索引](SUBMISSION.md) | 索引实际版本、判断、失败、修订、复验与迁移，不预填成功 |

**操作顺序：**核对 L01 练习仓库 → 查依据并作规则判断 → 保存 N0 → 修改 AGENTS → 全新任务 N1 与合法对照 → 程序回归 → 反馈与迁移。

个人材料放在自己的 `lesson-02-submission/`；已有记录继续追加，示例与课程参考结果不代替本人证据。

按需材料：

- [write-agents/SKILL.md](write-agents/SKILL.md) 是第 4 步采用的规则写作练习，保留其配套目录。
- `assets/` 为正文配图及来源记录，随正文查看。
- [reference/参考说明](reference/参考说明.md) 提供深层参考与历史索引，完成主线后按需查看。
- [唯一课堂课件](L02-把仓库规则写进AGENTS.md-流程实例版.pptx) 随课堂使用，操作以当前手册为准；历史版本已归档。
