- 看不懂业务规则或判断理由：回到辅导资料的对应案例。

### 学习路线

1. **看清问题**：区分记录完整与人工审核，知道本次允许改什么。
2. **写好规则**：从事实提炼目录职责、禁止事项、验证命令和完成条件。
3. **亲手复验**：先保存改前响应 N0，再写规则；新会话用相同请求得到 N1，检查越界和合法工作。
4. **解释与迁移**：说明个人取舍和证据，把同一种判断迁移到采购审批。

线上课为 29 分钟内容加 1 分钟机动。实操建议分两段约 90 分钟，模型等待、程序运行和修订时间另计。第一次做时按手册顺序走；熟悉工具的同学可以略过界面导览，但不能跳过首次判断、前测和复验。

### 本讲完成什么

起点是 L01 中自己完成的个人研发工作台。本讲仍由学生直接监督 Codex，工作台新增可供后续会话继承的约定，FlowERP 业务账不变。你交付根目录 `AGENTS.md` 的实际改进，以及包含事实来源、前后回答、个人取舍、反馈和迁移答案的学习记录。

截图展示教师环境或教师实测，不替代学生证据。已有程序检查通过，也不能单独证明规则被采用或人工已接受。前后回答都正确时如实记录，不制造失败。
