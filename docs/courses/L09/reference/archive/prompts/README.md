# L09 提示词

先形成个人判断，再选用提示词。它们帮助组织协作，不会自动建立权限或替你作接受决定。

1. [区分事实与原因](../../../实践操作手册.md#codex-prompt-1)：核对来源，调查取消与释放。
2. [实现有界修复](../../../实践操作手册.md#codex-prompt-2)：按确认范围实现映射器和业务修复。
3. [复验与反证](../../../实践操作手册.md#codex-prompt-3)：从原始证据检验结论。

配套 [Skill](../../../examples/skills/repair-task-review/SKILL.md)用于提炼审查方法；实际采用与修订写入[提交模板](../../../SUBMISSION.md)。
