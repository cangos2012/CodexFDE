# L09 个人提交

关联已有记录的实际路径，保留首次判断、原始失败和修订。参考实验只作观察，不能填写成本人的映射器建设或业务修复。

## 1 起点和首次判断

- 姓名、日期、实际事项编号、业务口径确认者：
- 问题来源与影响对象（实际观察／同伴试用／教学设置）：
- 控制工作台、个人候选、来源与版本，已有修改：
- TARGET／OTHER 取消前后的独立预测，草稿、重复和已发货取消的处理决定：
- 本人选择的范围、暂缓项及依据；报告缺字段或来源不明时的首次判断：

## 2 映射器建设任务

- 建设 Spec、实际 Task ID、允许的 agent／eval／tests 具体文件：
- 候选实际加载的映射器与 CLI 版本，哪些是参考已有、哪些由本人新增：
- 严格草案、无阻断不生成任务、无效报告退出 2 的实际检查与结果：
- 三项个人取消检查的名称、登记入口、固定版本及独立预期：
- 建设 Diff 与控制器测试结果；未修业务的依据，阶段接受者或待审核状态：

## 3 本轮红报告与个人映射草案

- 三项个人检查的实际命令、候选、原报告、即时退出码及业务失败原因：
- 个人映射器实际调用命令、输出与退出码：
- 草案里的来源任务、候选、报告 SHA-256、源码版本、复现与验收命令：
- 哪些字段由工具生成、哪些可信上下文由本人确认；无效输入时的实际行为：

## 4 本人确认后的业务修复

- 本人接受的草案与修订理由，原草案保存位置：
- 业务修复 Spec、第二个 Task ID，来源任务如何连到建设任务：
- 业务写集、每个文件的必要性、冻结映射器与检查的依据：
- 同一候选的修复前红、范围内 Diff、原三项修复后报告与完整 blocking 结果：
- TARGET 释放、OTHER 保留及拒绝／写入失败后状态的实际核对：
- 自动检查结论与本人接受／退回／依据不足的决定、实际姓名和日期：

## 5 同伴反证与修订

- 同伴姓名或“仅自查，待同伴复验”：
- OTHER 的 A 预占改为 3 时，同伴的独立预测与实际结果：
- 原反馈、本人回应、修订前后版本与复跑依据：
- 未解决问题、实际使用反馈与尚未验证的效果：

## 6 提炼与迁移

- repair-task-review Skill 的实际输入、响应及一项正确判断或遗漏：
- 本人修订及原证据位置：
- 迁移到“采购申请原因丢失”时，需重新取得的报告、确认的目标与业务写集：
- 后续真实复用的任务／版本／结果，或明确待验证状态：

工具可以整理证据路径；本人负责业务口径、授权范围、判断和接受。没有真实执行或反馈时标待完成，不生成署名，不提交密钥、运行数据库或未经授权的个人材料。

完成手册中的个人建设、同案复验与审核后再进入下一讲，缺项回本讲续做。
