# 历史错误与当前状态

方式：内置 ImageGen。教学插画，不是实际运行或验收证据。

定稿：[08-error-history.png](08-error-history.png)。

## 提示词

Use case: scientific-educational. 为中文成人AI工程课程PPT制作一张教学插画，不是整页幻灯片。横向16:9，纯白背景，深海军蓝文字与轮廓，蓝绿区分正常，橙红提示风险，简洁专业的扁平立体纸张、电脑、存储器插画，视觉舒展，避免彩色卡片墙。中文无衬线字大而清晰，标签少，绝不添加长段文字，不添加标题或页码。不要假装真实运行截图。同一本任务记录左右摊开两页。左页标题‘历史’，两行分别‘第一次检查失败’‘保留原因与修订’使用橙色和深蓝。右页标题‘当前’，两行‘最新报告通过’‘等待人审核’使用绿色和深蓝。中间小标签‘任务 T-001’，两页属于同一任务。不得把左页失败删除或划掉，不能把右页画成已完成。底部简短‘旧错误留在历史，当前待办写清楚’。
