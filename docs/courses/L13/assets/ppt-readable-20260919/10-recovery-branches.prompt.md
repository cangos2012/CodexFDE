# 不同中断采用不同恢复策略

方式：内置 ImageGen。教学插画，不是实际运行或验收证据。

定稿：[10-recovery-branches.png](10-recovery-branches.png)。

## 提示词

Use case: scientific-educational. 为中文成人AI工程课程PPT制作一张教学插画，不是整页幻灯片。横向16:9，纯白背景，深海军蓝文字与轮廓，蓝绿区分正常，橙红提示风险，简洁专业的扁平立体纸张、电脑、存储器插画，视觉舒展，避免彩色卡片墙。中文无衬线字大而清晰，标签少，绝不添加长段文字，不添加标题或页码。不要假装真实运行截图。上下两个简洁场景。上行左检查报告与暂停符号‘verify 检查中断’，中间重复检查图标‘受控重放’，右空椅子‘通过后等待审核’。下行左电脑上半份修改文件‘codex 修改中断’，中间橙色停止符号‘dead_letter’，右真实人查看差异文档‘人工核对后决定’。底部一行‘已有明确失败的 rework，不因重启无限重试’。上下独立流程箭头，不能连错；不把codex修改自动重跑，不把dead_letter画成删除任务，不画已批准。
