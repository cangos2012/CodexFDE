# 状态背后的事件与报告

方式：内置 ImageGen。教学插画，不是实际运行或验收证据。

定稿：[06-state-evidence.png](06-state-evidence.png)。

## 提示词

Use case: scientific-educational. 为中文成人AI工程课程PPT制作一张教学插画，不是整页幻灯片。横向16:9，纯白背景，深海军蓝文字与轮廓，蓝绿区分正常，橙红提示风险，简洁专业的扁平立体纸张、电脑、存储器插画，视觉舒展，避免彩色卡片墙。中文无衬线字大而清晰，标签少，绝不添加长段文字，不添加标题或页码。不要假装真实运行截图。一份打开的任务档案‘T-001’为主画面，左侧大标签‘当前：等待审核’，右侧展开三种纸质材料：‘事件：检查已结束’、‘候选：X’、‘报告：检查 X 通过’。上方小钟表示时间，纸张各自可读，关联线都指向同一任务档案。底部一份尚未签署的表单‘审核决定：待填写’。不画已经批准，不添加假姓名、真实时间或数据，视觉强调状态有对应证据。
