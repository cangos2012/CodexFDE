# 审核必须对应当前版本

方式：内置 ImageGen。教学插画，不是实际运行或验收证据。

定稿：[07-review-version.png](07-review-version.png)。

## 提示词

Use case: scientific-educational. 为中文成人AI工程课程PPT制作一张教学插画，不是整页幻灯片。横向16:9，纯白背景，深海军蓝文字与轮廓，蓝绿区分正常，橙红提示风险，简洁专业的扁平立体纸张、电脑、存储器插画，视觉舒展，避免彩色卡片墙。中文无衬线字大而清晰，标签少，绝不添加长段文字，不添加标题或页码。不要假装真实运行截图。左右两组电脑与检查纸，左边‘候选 X’和‘报告 R-X’，二者之间细线，旁边审核章‘批准 X’。右边电脑‘候选 Y’和空白检查纸‘Y 需要重新检查’，审核空表‘Y 需要重新审核’。中间淡灰向右说明‘代码已改变’，左边批准章不能盖在Y上，在跨到Y的虚线处有橙色叉标‘旧批准不沿用’。字体大，只写指定文字。教学设计条件示意，不是原实现已具备证明。
