# 提交去重与收货去重

方式：内置 ImageGen。教学插画，不是实际运行或验收证据。

定稿：[05-two-idempotency.png](05-two-idempotency.png)。

## 提示词

Use case: scientific-educational. 为中文成人AI工程课程PPT制作一张教学插画，不是整页幻灯片。横向16:9，纯白背景，深海军蓝文字与轮廓，蓝绿区分正常，橙红提示风险，简洁专业的扁平立体纸张、电脑、存储器插画，视觉舒展，避免彩色卡片墙。中文无衬线字大而清晰，标签少，绝不添加长段文字，不添加标题或页码。不要假装真实运行截图。上下两个相互独立的场景。上行重复两个信封都标‘提交键 K’，共同对应一份文件‘任务 T-001’，结果‘只建立一个任务’。下行两次仓库收货请求都标‘同一收货键’，账本显示‘在库 10 + 7 = 17’，旁边‘本次流水：1 条 +7’，结果‘重试后仍为 17’。上下行中间没有自动蕴含的箭头。最底部橙色字‘一个任务仍可能多次调用收货’。避免把任务键K当作收货键，不画24，不画审批自动发生。
