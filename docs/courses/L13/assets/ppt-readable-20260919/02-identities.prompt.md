# 需求、研发任务与采购单

方式：内置 ImageGen。教学插画，不是实际运行或验收证据。

定稿：[02-identities.png](02-identities.png)。

## 提示词

Use case: scientific-educational. 为中文成人AI工程课程PPT制作一张教学插画，不是整页幻灯片。横向16:9，纯白背景，深海军蓝文字与轮廓，蓝绿区分正常，橙红提示风险，简洁专业的扁平立体纸张、电脑、存储器插画，视觉舒展，避免彩色卡片墙。中文无衬线字大而清晰，标签少，绝不添加长段文字，不添加标题或页码。不要假装真实运行截图。画三个具有明确区别的对象，左一份需求说明纸，中间一本研发任务档案，右一张采购单和少量货箱。对象沿水平方向排开，通过细的无方向关联线连接，不要画自动执行箭头。文字仅：左‘需求’‘先审批，再入库’，中‘任务 T-001’‘Spec / 候选 / 报告 / 审核’，右‘采购单 PR-TARGET’‘商品 A，7 件’。右边货箱不是已经交付的证据，不画成功勾或批准章。中间任务突出为持久记录，其余物件稍小。
