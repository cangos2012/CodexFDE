# 服务重启后保留下来的内容

方式：内置 ImageGen。教学插画，不是实际运行或验收证据。

定稿：[09-memory-storage.png](09-memory-storage.png)。

## 提示词

Use case: scientific-educational. 为中文成人AI工程课程PPT制作一张教学插画，不是整页幻灯片。横向16:9，纯白背景，深海军蓝文字与轮廓，蓝绿区分正常，橙红提示风险，简洁专业的扁平立体纸张、电脑、存储器插画，视觉舒展，避免彩色卡片墙。中文无衬线字大而清晰，标签少，绝不添加长段文字，不添加标题或页码。不要假装真实运行截图。左右对照但不是卡片网格。左一台服务器标‘旧服务进程’，其上方半透明便签标‘内存队列’，进程停止的橙色电源符号，便签淡去。画面下方一枚硬盘和整齐档案标‘已保存的任务与事件’，保持清晰不淡去。右新服务器标‘新服务进程’，从硬盘读取一份标‘原任务 T-001’的档案。底部文字‘记录可以找回，是否继续还要判断’。不画自动成功、不画删除数据库，不用火焰或爆炸。
