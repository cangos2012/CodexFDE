# 返回受理与后台执行分开

方式：内置 ImageGen。教学插画，不是实际运行或验收证据。

定稿：[04-async.png](04-async.png)。

## 提示词

Use case: scientific-educational. 为中文成人AI工程课程PPT制作一张教学插画，不是整页幻灯片。横向16:9，纯白背景，深海军蓝文字与轮廓，蓝绿区分正常，橙红提示风险，简洁专业的扁平立体纸张、电脑、存储器插画，视觉舒展，避免彩色卡片墙。中文无衬线字大而清晰，标签少，绝不添加长段文字，不添加标题或页码。不要假装真实运行截图。以两行时间线讲异步，时间从左向右。上行左人物和笔记本‘调用方’，信封‘提交’，中段返回信封‘收到 202 与 T-001’，右侧手机‘稍后查询 T-001’。下行左服务器‘保存任务’，其后长条简洁机械工作场景标‘后台继续检查’，右侧审核人空椅子‘等待审核’。连接关系明确：提交到保存任务、保存任务后返回202，后台继续检查不用等待上行手机查询。底部一句‘返回受理时，检查可以尚未结束’。不画完成或采购入库，不添加秒数或伪实测数据。
