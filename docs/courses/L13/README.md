# L13｜把执行链路封装成任务 API

提交成功、研发交付完成、采购入库是三个不同的事实。本讲以补货需求串起任务身份、异步执行、幂等提交、持久状态和恢复，让离开页面后仍能找回同一任务及其证据。

先读[辅导资料](辅导资料.md)，再按[实践操作手册](实践操作手册.md)完成参考观察与个人实现。操作时用[行动卡](行动卡.md)查漏，用[提交模板](SUBMISSION.md)整理原始记录。

需要时使用[三阶段提示词](prompts/README.md)和[任务 API 审查 Skill](skills/task-api-review/SKILL.md)。[参考 HTTP 实验](examples/task_api_lab.py)使用真实课程 Eval 与隔离任务库；它不运行 Codex，不替代新增 ERP 功能或真实人的审核。图解随正文阅读，无需单独学习。

配套资料：[辅导资料](辅导资料.md)、[实践操作手册](实践操作手册.md)，可按需查阅。

[课堂 PPT（30 页）](slides/L13-把执行链路封装成任务API-图文案例版-30页.pptx)按七个连续案例展开；讲义末尾提供案例、页码与实践步骤索引。
