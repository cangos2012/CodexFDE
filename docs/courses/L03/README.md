# L03｜把模糊需求变成可验收 Spec

## 第一次打开，按这条路线走

把库存导出需求写成确认版 Spec，并建设只校验结构的解析器。

**开始前准备：** 自己的工作台和待澄清的库存导出需求。

| 顺序 | 打开什么 | 现在做什么，做到哪里再继续 |
|---|---|---|
| 1. 看懂本讲任务 | [辅导资料](辅导资料.md) | 先读开头的案例或总览，写下本讲要解决的问题；原理随实践回查 |
| 2. 开始操作 | [实践操作手册](实践操作手册.md) | 手册第 1～3 步：回答需求问题，形成 V1 和确认版；能说明每个决定的来源及验收方式 |
| 3. 完成本人实现 | [实践操作手册](实践操作手册.md) | 第 4～6 步：提炼模板、实现解析器，用三份合同复验 |
| 4. 复验与交接 | [行动卡](行动卡.md)及手册末尾 | 核对手册最后 8 项，保留结构拒绝与语义审查结论 |

**个人记录放哪里：** 手册指定的本讲目录；SUBMISSION.md 用于扩展记录。报告、截图和教师示例用于对照；个人结论填写实际观察，尚未复验就注明待复验。

## 遇到问题，回到哪个入口

- 看不懂业务规则或判断理由：回到辅导资料的对应案例。
- 不知道在哪输入、缺少文件、命令报错或中途重开窗口：回到实践手册的准备、排错或恢复步骤，先确认原会话与候选。
- 不知道某个脚本能否直接运行：先查手册是否调用它；参考实验与个人交付按手册区分。
- 同一主题有多份 PPT、图或历史记录：按课堂指定版本使用；首次自学以当前辅导资料和实践手册为主。

下载或移动附件时保留本讲目录结构；只拷贝一个 Markdown 文件可能导致配图、Prompt 或脚本路径失效。

## 按需参考：已有实验说明与资料记录

下面保留本讲已有说明，供查询实验机制、证据范围和课件记录。涉及历史实测、页数或同步状态的描述只对应原记录；当前学习顺序以上方导航为准。

本讲把“增加库存导出功能”变成可审查、可解析、可反驳的合同，并为个人工作台建设最小 Spec 解析器。库存导出业务由 L04 实现。

按下面的顺序使用材料：

1. 阅读[辅导资料](辅导资料.md)，理解“用途—决定—合同—结构闸门”的方法。
2. 按[实践操作手册](实践操作手册.md)完成需求访谈、库存 Spec、通用模板、解析器和三种输入复验。
3. 需要课堂速查时再使用[行动卡](行动卡.md)；需要扩展记录时再参考[提交模板](SUBMISSION.md)。

本讲最终应留下三项可复用成果：实际确认的库存合同、能起草不同需求的六部分模板、已接入工作台入口的个人解析器。课堂先理解主线，完整编码、同伴审查与迁移在实践环节完成。

实践所需的 Prompt 已放在具体步骤中，使用到时直接复制。审查 Skill 和样稿只在相应步骤按需打开，不需要预先通读。L04 将消费同一份确认版库存合同；结构通过不代表业务正确，也不代表导出功能已经交付。

配套资料：[辅导资料](辅导资料.md)、[实践操作手册](实践操作手册.md)，可按需查阅。
