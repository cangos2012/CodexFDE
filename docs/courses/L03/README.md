# L03｜把模糊需求变成可验收 Spec

本讲把“增加库存导出功能”变成可审查、可解析、可反驳的合同，并为个人工作台建设最小 Spec 解析器。库存导出业务由 L04 实现。

按下面的顺序使用材料：

1. 阅读[辅导资料](辅导资料.md)，理解“用途—决定—合同—结构闸门”的方法。
2. 按[实践操作手册](实践操作手册.md)完成需求访谈、库存 Spec、通用模板、解析器和三种输入复验。
3. 需要课堂速查时再使用[行动卡](行动卡.md)；需要扩展记录时再参考[提交模板](SUBMISSION.md)。

本讲最终应留下三项可复用成果：实际确认的库存合同、能起草不同需求的六部分模板、已接入工作台入口的个人解析器。课堂先理解主线，完整编码、同伴审查与迁移在实践环节完成。

实践所需的 Prompt 已放在具体步骤中，使用到时直接复制。审查 Skill 和样稿只在相应步骤按需打开，不需要预先通读。L04 将消费同一份确认版库存合同；结构通过不代表业务正确，也不代表导出功能已经交付。

配套资料：[辅导资料](辅导资料.md)、[实践操作手册](实践操作手册.md)，可按需查阅。
