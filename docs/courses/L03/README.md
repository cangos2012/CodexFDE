# L03｜把模糊需求变成可验收 Spec

沿用前两讲的工作台与规则，先确认库存导出合同，再建设模板与解析器；产品实现留到 L04。

只按一条路线学习：先读讲义理解本讲问题，再在手册中逐步操作，最后用提交索引核对自己的证据。

| 主文件 | 何时使用 |
|---|---|
| [辅导资料](辅导资料.md) | 理解案例、机制和设计判断；原理随实践回查 |
| [实践操作手册](实践操作手册.md) | 按步骤完成目标、操作、结果与排错；提示词就在首次使用步骤内 |

个人材料放在自己的 `lesson-03-submission/`；已有记录继续追加，示例与课程参考结果不代替本人证据。
