# L03 Spec 修订与判断边界图提示词

- 工具：Codex 内置 ImageGen
- 类型：scientific-educational
- 用途：L03 实践操作手册第 3 步总览图

```text
创建一幅 16:9 中文教学信息图。左半部分按顺序呈现“写出 V1 → 用反例找歧义 → 人作决定 → 形成确认版”，并使用“同一 SKU 分布在多仓、多仓位、多批次，到底输出几行？”作为反例。右半部分用两栏区分“解析器”和“人”的职责：解析器检查六个章节齐全、顺序正确，但不会判断库存公式；人确认一行代表什么、公式和错误处理。使用深蓝、青绿、琥珀和少量红色，文字清晰，箭头不交叉，不声称库存导出已经实现。
```
