# L03 分步图解：设计与 ImageGen 提示词

目的：让初学者通过具体库存、文件和输入输出理解正文。使用内置 ImageGen；全部是教学示意，不是运行截图或学员证据。原有图片保留。

阅读顺序：三个数量 → 两条明细 → 六个标题 → 两种边界情境 → 解析器与人的职责。每张图紧贴对应段落，不合并成复杂总览。

## 图 1：为什么 8 件货只能再卖 5 件

文件：`01-available-stock.png`

Use case: scientific-educational. 为中文成人初学者辅导资料生成一张真正帮助理解的教学插画。横向 3:2，高分辨率，纯白背景、深蓝黑中文无衬线大字、柔和蓝/橙/绿色、极简平面纸张和实物插画。中文文字必须准确清晰。每张只讲本题，不使用思维导图，不用装饰网络、复杂连线、渐变、机器人、假软件截图或微小文字。留白充足，所有内容不超出边界。图中内容是教学示意，不是运行证据。 标题“为什么有 8 件，只能再卖 5 件？”。画面中央画同一货架上的八个完全等大的商品纸箱，严格为8个，排列一行或两行；其中三个橙色箱贴小标签“已留给订单”，另外五个蓝色箱无订单标签。用一个总括号包住全部八个，标签“在库 8 件”；再分别用清晰独立括号指向3个橙箱，标签“预占 3 件”，和5个蓝箱，标签“可用 5 件”。底部巨大的算式“8 − 3 = 5”，下方一句“货还在仓库，但有 3 件已经答应给别人”。要把三个数量画成同一批货的整体与两部分，不是三组相互独立的货物。仅出现上述必要文字与小角标“教学示意”。

## 图 2：为什么同一商品要保留两行

文件：`02-detail-rows.png`

Use case: scientific-educational. 为中文成人初学者辅导资料生成一张真正帮助理解的教学插画。横向 3:2，高分辨率，纯白背景、深蓝黑中文无衬线大字、柔和蓝/橙/绿色、极简平面纸张和实物插画。中文文字必须准确清晰。每张只讲本题，不使用思维导图，不用装饰网络、复杂连线、渐变、机器人、假软件截图或微小文字。留白充足，所有内容不超出边界。图中内容是教学示意，不是运行证据。 标题“同一商品，为什么保留两行？”。上方一句使用需求“我要知道还能卖多少，也要知道货在哪”。中部左侧上下排列两个小仓库插画，分别标“东仓：可用 5 件”和“西仓：可用 3 件”，均标“商品 A”。两条短水平箭头分别从仓库准确连接到右侧表格各自的数据行；表格标题“本次选择：保留位置”，三列仅“商品”“仓库”“可用量”，第一行“A / 东仓 / 5”，第二行“A / 西仓 / 3”。不要画八字段完整数据表，这是简化说明。下方独立浅灰对照卡“合并成一行：商品 A，共 8 件”，旁注“总数没错，但找不到仓库位置”，标记“本次不用”，不要表示汇总本身永远错误。底部结论“先问用途，再决定一行代表什么”。小角标“教学示意”。

## 图 3：六个标题各装什么内容

文件：`03-six-sections.png`

Use case: scientific-educational. 为中文成人初学者辅导资料生成一张真正帮助理解的教学插画。横向 3:2，高分辨率，纯白背景、深蓝黑中文无衬线大字、柔和蓝/橙/绿色、极简平面纸张和实物插画。中文文字必须准确清晰。每张只讲本题，不使用思维导图，不用装饰网络、复杂连线、渐变、机器人、假软件截图或微小文字。留白充足，所有内容不超出边界。图中内容是教学示意，不是运行证据。 标题“把谈清楚的内容，放进六个位置”。画成一张正面展开的、整洁可读的需求说明纸张，纸张上方文件名“FDE_SPEC.md”。内部六个横条，自上而下依次编号1至6，每条左侧中文标题，右侧一条具体短示例。精确顺序与文字：1“来源”对应“谁提出：运营要看可售数量和位置”；2“目标”对应“做什么：导出库存明细”；3“非目标”对应“不做什么：不发邮件、不自动补货”；4“约束”对应“遵守什么：只读；可用量 = 在库量 − 预占量”；5“验收用例”对应“怎样检查：在库 8，预占 3，应得到 5”；6“完成定义”对应“本讲交接：确认说明，验证读取工具”。纸旁不要再增加一套流程，六条总共只用两种淡色交替，约束和例子可通过小短竖标强调一般规则与具体数字的对应。底部醒目一句“先说清内容，再放入标题；不是只把空格填满”。小角标“缩略教学示意”。禁止将本讲描述为已经实现库存导出。

## 图 4：先约定没有数据和写出失败时怎么办

文件：`04-export-edge-cases.png`

Use case: scientific-educational. 为中文成人初学者辅导资料生成一张真正帮助理解的教学插画。横向 3:2，高分辨率，纯白背景、深蓝黑中文无衬线大字、柔和蓝/橙/绿色、极简平面纸张和实物插画。中文文字必须准确清晰。每张只讲本题，不使用思维导图，不用装饰网络、复杂连线、渐变、机器人、假软件截图或微小文字。留白充足，所有内容不超出边界。图中内容是教学示意，不是运行证据。 标题“没数据，和写失败，不是一回事”。左右两个宽敞场景，阅读方向左到右但不画两场景互相连接。左侧标题“没有库存记录”，一个表格文件插画，仅一行表头，表头显示八个简单等宽空列格，用括号标注“保留八列表头”，下方不画任何数据行，旁边文字“没有数据行”，绿色结论“结果为空，仍是有效文件”。右侧标题“写文件中途失败”，左边一个标有“原有有效文件”的完整纸张，保持蓝色不划掉；旁边一个标有“本次半成品”的破损纸张，用橙红禁止发布标记；下方两条精确文字“原有文件不变”“没有原文件，也不留下半成品”，橙红结论“明确报错，不发布半份结果”。底部跨全宽一句“导出成功或失败，都不能改库存和流水”。小角标“本例约定 · 教学示意”。用真正的文件/空表插画解释状态，不能只是文本卡片堆叠。

## 图 5：解析器通过不等于需求正确

文件：`05-parser-boundary.png`

Use case: scientific-educational. 为中文成人初学者辅导资料生成一张真正帮助理解的教学插画。横向 3:2，高分辨率，纯白背景、深蓝黑中文无衬线大字、柔和蓝/橙/绿色、极简平面纸张和实物插画。中文文字必须准确清晰。每张只讲本题，不使用思维导图，不用装饰网络、复杂连线、渐变、机器人、假软件截图或微小文字。留白充足，所有内容不超出边界。图中内容是教学示意，不是运行证据。 标题“读得出来，不等于写得正确”。两个上下排列的宽场景，分别独立横向左到右。第一行输入纸张图，标题“缺了‘非目标’”，可画六条中的第三条空白橙色虚线；短箭头到工具图标“解析器”，再短箭头到橙色结果“拒绝：缺少一个部分”。第二行输入纸张图，标题“六部分齐全”，正文强调错误算式“可用量 = 在库量 + 预占量”；短箭头到工具图标“解析器”，绿色结果“可以读取”，其后再短箭头到人拿笔核对的简洁插画，橙色结果“内容要改：8 + 3 = 11，不是可用量”。最底部明确两句“程序检查格式；人核对用途、公式和例子”“本例正确：8 − 3 = 5”。重要：第二行的绿色只表示读取格式成功，绝不把错误算式标正确；不要画成程序会自动发现所有业务错误。小角标“教学示意”。


## 定向修订与最终复核

已逐张查看生成结果。图 1 核对为 3 个橙色箱与 5 个蓝色箱；图 2 两条箭头分别指向两条数据行，仓库仅作位置图标；图 3 六标题顺序与正文一致；图 4 仅保留一行八列表头；图 5 使用正式六标题，区分结构接受与人工语义检查。未把教学插画当作实际运行记录。

### 图 2 的最终修订提示词

精准修改这张教学图，保留全部标题、配色、文字和三列表格。只修改两处：一、左边东仓和西仓建筑内部的小箱子全部去掉，改为空仓库门图标，避免装饰箱子的数量被误读成实际件数；底部灰色合并卡的小箱子也去掉，保留文字。二、两条箭头要从各仓库标签出发，准确连接右侧对应的数据行中心：东仓箭头连接 A / 东仓 / 5 所在第一条数据行；西仓箭头连接 A / 西仓 / 3 所在第二条数据行；严禁东仓箭头指向标题或列名行。可使用短折线，线不交叉。其他内容不变。

### 图 4 的最终修订提示词

精准修改左侧的空表图示，其他文字、版式、右侧插画、颜色全部保持。现有左侧表格画了两行，第二行空白数据行会造成误解。删除整个第二行空格，只保留一条蓝色表头行，这条表头行严格为8个格子。蓝色表头下面是完全空白纸张，不再有任何横线、竖线或数据格。保留‘保留八列表头’与‘没有数据行’的文字。

### 图 5 的最终修订提示词

修正此教学图中的输入纸张，两行的总体流程、图标、人物和右侧结果保持不变。重要错误：原图将六部分误画成在库量/预占量/计算公式等，必须改为课程真实六标题。上方纸张标题改为‘FDE_SPEC.md’，纸内从上到下只显示：‘1 来源’、‘2 目标’、一条橙色虚线（第三部分整个缺失，不写非目标）、‘4 约束’、‘5 验收用例’、‘6 完成定义’。下方纸张标题同样改为‘FDE_SPEC.md’，从上到下必须准确显示‘1 来源’、‘2 目标’、‘3 非目标’、‘4 约束’、‘5 验收用例’、‘6 完成定义’。在下方纸张第四条下面用橙色小行写‘可用量 = 在库量 + 预占量’，其余标题正文用细灰横线代替，禁止编造‘非目标：损耗量’，禁止添加别的章节名。保留下方的‘六部分齐全’‘可以读取’‘内容要改：8 + 3 = 11，不是可用量’和底部正确算式。可以略微扩大纸张宽度保证六个中文标题清楚，不要增加文字或改成一个正确公式的输入，错公式正是本图的教学反例。
