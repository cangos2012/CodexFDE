# L08｜把同一套 Eval 接入 CI

交付整单原子预占；在同一候选完成 A 假绿、B 可信红、C 可信绿，判断业务和检查流程是否都足以交接。

按这条顺序完成，不需要先浏览所有附件：

1. [辅导资料](辅导资料.md)：理解本次现场问题、要求和判断依据。
2. [实践操作手册](实践操作手册.md)：准备个人候选，拆回课程与独立 FlowERP 两仓，固定远程产品版本，再完成 A 假绿、B 可信红、C 可信绿；目标、合同及 Codex 提示词都在对应步骤内。
3. [SUBMISSION：个人证据索引](SUBMISSION.md)：从首次判断开始关联已有记录，提交实际失败、Diff、复验与具名决定；未做项如实标待完成。

[唯一当前课件](L08-把同一套Eval接入CI.pptx)：保留同目录既有课堂课件。本轮未重验 PPT 内容，命令与完成标准按当前手册。

附件随手册使用：[examples](examples/) 保留脚本与 Skill，[assets](assets/README.md) 保留配图和来源。需要深入机制或历史版本时查[参考说明](reference/参考说明.md)，归档稿不构成另一条必做路线。

遇到路径、解释器或输出错误，先回手册准备与排错步骤恢复同一候选；预置支架通过和历史截图不能代替本人实现、真实宿主运行或人审。
