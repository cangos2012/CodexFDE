# L16｜在新环境接手，并完成现场新需求

另一位同伴必须按材料重建工作台和 FlowERP。系统运行后，业务人员再提出一个未预演的小需求，例如“查到当前页之外的本组织库存”。**本讲检验两件事：别人能接手已有系统，你能在新的条件下确认缺口并通过工作台交付新能力。**

![快速找库存先区分当前页过滤与跨分页查询，再确认本次规格](assets/imagegen-20260920/05-clarify.png)

从左边同一句诉求看两条分支：当前页筛选与跨分页查询需要不同实现和检查。先与提出者确认范围，再形成本次 Spec；若当前版本已实现，应调查另一真实缺口。图为教学示意。

本讲沿用 [L11 的分工](../L11/README.md)、[L12 的等待与恢复](../L12/README.md)、[L13～L14 的服务与页面](../L13/README.md)及 [L15 的经验治理](../L15/README.md)。新难度是陌生环境、陌生使用者和未预演需求。

## 按这条路线学习

1. [辅导资料](辅导资料.md)：跟随同伴接手，分清启动、业务健康、回退、恢复和新需求验收。
2. [实践操作手册](实践操作手册.md#lesson-goals)：冻结双仓版本，由同伴冷启动，再完成现场新需求、恢复与交付索引。
3. [提交模板](SUBMISSION.md)：分别记录冷启动证据与新需求证据，准备五分钟答辩和技术债说明。

**本讲动作线：**冻结两个仓库与环境 → 同伴独立冷启动 → 现场确认未实现需求 → 新检查先红 → 范围内实施后绿 → 具名复验 → 恢复、导出、反馈与答辩。
