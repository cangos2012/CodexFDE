## 验证边界

默认 Git/CI 检查课程合同、已发布资源链接和蓝图。两项依赖本地 PPT 的检查明确跳过，不据此声称课件通过。具备完整本地课件时可单独执行：

```powershell
$env:CODEXFDE_VALIDATE_LOCAL_SLIDES = "1"
.\.venv\Scripts\python.exe -X utf8 -m unittest tests.test_course_pptx tests.test_course_ppt_endings -v
Remove-Item Env:CODEXFDE_VALIDATE_LOCAL_SLIDES
```

正式课件有多个候选版本时，先由维护者明确待验收版本。结构、结束页检查不能替代逐页渲染与内容审核。固定 22 页是早期蓝图安排，不是当前所有课件的统一页数合同。
