# L12｜按问题查阅的参考说明

首次学习按[实践手册](../实践操作手册.md)推进。本页保留独有机制边界和历史索引，基础案例不重复展开。

2026-10-03 本次整理核对现有材料与所列源码；没有重跑历史实验，也不替学生取得真实执行、人审或迁移证据。

## 1. 对象比状态名更重要

轻量对象卡可列采购申请、审批、入库事件、库存、软件候选、Eval 和审核决定，说明身份、关系、约束、来源与确认状态。它是 Graph 设计支架，不要求实现 OWL，也不是完整语义系统。

`approved` 可能指业务批准或软件接受，两者不能替代。审批绑定单据，交付审核绑定候选与报告；候选改变后旧批准不自动有效。

## 2. 当前 Graph 的实际边界

[`agent.graph`](../../../../agent/graph.py)的 develop 目前推进标签，没有直接运行 Codex。默认演示可自动批准；带状态文件或显式要求人审时进入等待。非空 reviewer 字段不证明真实人员已决定。

主循环异常可进入 failed，但读取在 try 之前、保存在其后；读取或写入失败不能伪称已持久化结构化失败。保存状态也不自动证明业务副作用能够安全恢复。
