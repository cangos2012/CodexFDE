# L10 个人提交

关联已有记录的实际路径，保留首次判断和真实修订。个人 Loop 建设、业务修复与安全停止分别填写；合成控制实验和预设补丁不能代替真实模型修复。

## 1 起点和设计判断

- 姓名、日期、实际事项编号、业务口径确认者：
- 问题来源与影响对象（实际观察／同伴试用／教学设置）：
- 控制工作台、来源候选及版本、已有修改：
- 合法发货和三种拒绝的独立预期、OTHER 的保护要求：
- 一轮的定义、最后一轮允许做什么、继续或交回人的判断依据：
- 轮数／时间／Token 预算、未知用量处理；范围选择、暂缓项与理由：

## 2 只建设 Loop，保留业务红

- 建设 Spec、实际 Task ID、agent／eval／tests 写集与实现 Diff：
- 个人 Loop 和四项检查的版本；参考已有与本人新增能力的界线：
- 个人入口读取运行上下文、选择实际检查、通过控制工作台创建限定任务的接线检查：
- 控制器测试结果与替身来源；业务未被修完的 Diff 依据及实际业务红报告：
- 该阶段接受者、理由或待审核状态：

## 3 从新版候选复制两个相同起点

- 建设候选、收敛副本、停止副本的实际路径与复制清单：
- 三者 Loop／检查／业务源码指纹及候选实际模块加载位置：
- 两副本各自执行前报告、即时退出码与相同业务失败依据：
- 各自确认的业务 Spec、运行上下文、来源任务和逐文件业务范围：

## 4 真实业务修复轨迹

填写实际发生的轮次，不将参考起点绿灯写成修复。

| 轮次 | 检查版本与原报告 | 阻断失败与原因 | 实际任务及 Diff | 用量与时间 | 修改后检查或待复验 |
|---|---|---|---|---|---|
| 1 | | | | | |
| 2 | | | | | |
| 3 | | | | | |

- 实际模型执行、任务来源、候选与范围的依据：
- 最新修改与最后已检查版本的关系，原四项检查和完整回归结果：
- 收敛或实际停止的运行编号、退出码与结论；无执行器／认证时的待完成项：
- 合法发货 6／2／4、OTHER 不变及非法拒绝后四表不变的实际核对：

## 5 相同业务红起点的安全停止

- 停止副本与收敛副本修复前版本相同的依据：
- `--max-rounds 1` 的实际命令、原报告、即时退出码与停止原因：
- 实际检查次数、编码次数、业务指纹；剩余失败和最后已验证版本：
- 是否达到“一次真实检查、零次编码”；未达到时保留的 Diff、原因与重验：
- 业务仍未完成的范围、负责人接手动作与待复验状态：

## 6 同伴、接受与迁移

- 同伴姓名或“仅自查，待同伴复验”；改变 OTHER 数量后的独立预期与结果：
- 同伴对候选接线、末轮、预算或合法路径的反例：
- 原反馈、本人回应、修订前后版本与实际复跑：
- 本人分别对业务修复和控制器停止作出的决定、实际姓名、理由与日期：
- loop-stop-review Skill 的实际输入、响应、一项正确判断或遗漏及本人修订：
- 新修复问题中重新确认的目标／范围／预算／检查版本，真实采用记录或待验证状态：
- 剩余风险、使用反馈与尚未验证的效果：

工具可以整理运行记录；本人负责授权、停止策略与接受。没有真实执行或反馈时标待完成，不生成署名，不提交密钥、运行数据库或未经授权的个人材料。
