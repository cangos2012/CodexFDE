# L11｜按问题查阅的参考说明

首次学习按[实践手册](../实践操作手册.md)推进。本页保留独有机制边界和历史索引，基础案例不重复展开。

2026-10-03 本次整理核对现有材料与所列源码；没有重跑历史实验，也不替学生取得真实执行、人审或迁移证据。

## 1. 声明检查与实际隔离

[`agent.schedule`](../../../../agent/schedule.py)比较声明的写写、写读、目录覆盖、输入版本和共享资源冲突；它不观察所有真实读写，也不创建沙箱或锁。漏报读集可能被允许，需要从工具活动反查合同。

共同输入应固定到实际版本与未提交差异，主 Agent 并行期间也不能改双方依赖的实现。输出文件不同不足以证明独立：临时库、报告目录、端口和接口变更仍可能共享。

## 2. 同版分歧与主结论

版本相同而一份报告绿、另一份红可能来自检查覆盖不同。先追溯实际字段与库存断言，再决定修复；不能因版本相同删除风险，也不能把摘要拼接当作整合。

稳定采购身份不自动带来重试幂等。原实验的重复编号语义须按当前客户服务和 Spec 核对；接口变化会使旧子报告部分失效。性能对照要比较到可接受结果的总耗时、用量与覆盖范围。
