# 委托三：核对触发与恢复

审查这份实际证据包：____。按任务要求逐项核对业务、适配器与宿主三层证据。确认每份报告是否来自同一候选，是否覆盖新增多行和失败后状态检查。

指出返回 0 但内部失败、重入跳过冒充通过、测试替身冒充真实事件、控制仓库报告冒充候选报告的情况。没有原始证据就标为缺失，不推测补全。

输出事实、矛盾、待验证项与最小补证步骤，并提出一个改变数量或故障位置的迁移问题。实际同伴和本人分别完成复验与接受判断，不生成他人署名。

先列出本次核对阶段：业务、协议、真实子进程、宿主事件或最终交接。对于重入跳过，检查是否有新报告，再显式检查最终候选；对照 12000 分与迁移的 11100 分，不能让固定数字假修复通过。

最后分别判断：检查是否能发现目标错误；真实事件是否调用同一检查并反馈；最终订单是否足以接受。引用各自原始证据，评价首次诊断是否成立、工作台改进消除了什么遗漏以及留下什么缺口。
