## 报告消费者为什么要重新计算

报告写出 JSON 只证明有结构化输出。消费者还要核对实际用例名称与等级、分项状态、失败原因、耗时、汇总计数、总判决和进程退出码。缺用例、重复名称、未知选择、矛盾摘要和过期来源都可能使一份能解析的报告不能交接。观察告警保留，但不被转换为阻断失败。

本讲九项合同约束最小汇总器；四项登记保留个人 L05 检查并加入库存口径及教学观察项。它们不等于完整代理 Harness，也未自动提供逐项进程隔离、超时、重试、自主修复或具名接受。真实宿主触发到 L07 再验证，注册回执不能替代 Hook 行为。
