# 三个报告反例与一个迁移问题

1. 实际红报告：分项一阻断失败、两通过，摘要 block、退出 1。应确认报告内部一致，同时给出产品仍需返工。依据 assets/latest/01-stock-red.json。
2. 篡改摘要：分项不变，只把摘要写成 pass/零阻断。应列出重算差异，拒绝用该摘要放行；不能代改旧报告掩盖问题。
3. 错配退出码：原红报告搭配退出 0。应要求查本次调用与报告对应关系，不能只信任其中一个。
4. 迁移：一份导入辅助材料在本任务可告警；换到需要该材料才能完成操作的任务，须重新判断等级。说明具体使用者和失败后果，不能按“文档”二字统一降级。

前三项已由 eval.report_contract 在本轮教师实验运行，结果见 assets/latest/consumer-checks.json。这只验证确定性核对分支，不等于已经由模型采用本 Skill 或跨任务复用。
