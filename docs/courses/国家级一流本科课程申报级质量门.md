# 国家级一流本科课程申报级质量门

教师侧内部建设审查表，更新于 2026-10-03。本文恢复历史证据门，用于核对[建设方案](./国家级一流本科课程建设方案.md)与[课程蓝图](./课程蓝图.md)的材料和证据边界，不代表申报资格通过或课程认定。当前未作正式申报核验；缺证据的项目保持“待建设／待校方确认／待真实教学采集”，不得用生成内容补齐事实。

| 审查项 | 接受依据 | 当前处理与边界 |
|---|---|---|
| 16 讲课程合同 | 课表标题逐字匹配，大纲核心内容、演示结果、课内增量和通过标准贯穿材料 | 持续检查；文件检查不等于课堂交付或学生达成 |
| 两个运行成果 | 工作台与 FlowERP 独立运行，产品问题驱动工作台改进，再由产品复验 | 参考运行、个人构造和具名接受分别取证，不混用两套数据 |
| 学生中心与产出导向 | CLO、学生动作、独立判断和迁移证据相互对应 | 按现行建设方案与逐讲合同检查，真实达成待开课采集 |
| 混合式教学 | 线上精讲与线下实验、同伴反证、修订和迁移形成一条行动链 | 设计已列出；实际用时、支架效果与课堂实施记录待采集 |
| 真实教学成效 | 经授权的首次判断、失败、修订与独立检查，达成统计含分母 | 待真实教学采集，不用教学夹具、参考测试或模拟成绩替代 |
| 持续改进 | 误区来源、调整理由及下一轮等价任务结果可追溯 | 待真实教学与改进验证，不以满意度单独证明有效 |
| 课程与团队材料 | 学校课程身份、培养方案对应、学分学时、团队分工与审核 | 待校方确认，仓库不代签、不代填正式审核结论 |
| 正式申报适用性 | 正式使用前由校方核验当批官方文件，记录来源、日期和适用范围 | 当前未核验，不写“符合申报条件”；申报资格待校方确认 |
| 信息与证据诚信 | 来源、版本、授权与责任清楚，无敏感信息、伪造数据、凭据和运行库 | 发布前逐项审查，保留真实失败，未经授权的作品不发布 |

技术绿灯只证明实际覆盖到的参考行为。学生的真实起点、范围内实现、同候选复验、具名接受、独立解释、跨事项复用与真实教学效果属于不同层级证据，不能互相替代。课堂 PPT 另按蓝图选定版本、执行本地检查与逐页审核；恢复治理文件不表示本地课件已通过验收。
