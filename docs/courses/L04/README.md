# L04｜委托 Codex 执行一次最小变更

沿用 L01～L03 成果，先完成并独立接受 Workbench V0，再由它交付 FlowERP 库存导出。

只按一条路线学习：先读讲义理解本讲问题，再在手册中逐步操作，最后用提交索引核对自己的证据。

| 主文件 | 何时使用 |
|---|---|
| [辅导资料](辅导资料.md) | 理解案例、机制和设计判断；原理随实践回查 |
| [实践操作手册](实践操作手册.md) | 按步骤完成目标、操作、结果与排错；提示词就在首次使用步骤内 |
| [SUBMISSION 提交索引](SUBMISSION.md) | 索引实际版本、判断、失败、修订、复验与迁移，不预填成功 |

**操作顺序：**准备证据 → Ticket A 合同 → 直接监督 Codex 补齐 V0 → 非执行者接受 A → V0 创建并执行 B → 同候选独立复验 → 具名决定与交接。

个人材料放在自己的 `lesson-04-submission/`；已有记录继续追加，示例与课程参考结果不代替本人证据。

按需材料：

- `scripts/` 保留库存交付检查脚本；`examples/` 保存按需交接 Skill，按手册调用。
- `assets/` 为正文配图及来源记录，随正文查看。
- [reference/参考说明](reference/参考说明.md) 提供深层参考与历史索引，完成主线后按需查看。
- [唯一课堂课件](L04-委托Codex执行一次最小变更.pptx) 随课堂使用，操作以当前手册为准；历史版本已归档。
