# L04｜委托 Codex 执行一次最小变更

## 第一次打开，按这条路线走

先独立验收工作台 V0，再由它组织 FlowERP 库存导出。

**开始前准备：** L03 确认版 Spec、工作台与独立 FlowERP 环境。

| 顺序 | 打开什么 | 现在做什么，做到哪里再继续 |
|---|---|---|
| 1. 看懂本讲任务 | [辅导资料](辅导资料.md) | 先读开头的案例或总览，写下本讲要解决的问题；原理随实践回查 |
| 2. 开始操作 | [实践操作手册](实践操作手册.md) | 手册第 1～4 步：建设并独立复验 Ticket A；工作台 V0 获得真实接受决定，才启动 Ticket B |
| 3. 完成本人实现 | [实践操作手册](实践操作手册.md) | 第 5～6 步：通过 V0 执行库存导出并独立复验 |
| 4. 复验与交接 | [行动卡](行动卡.md)及手册末尾 | 第 7 步：接受或打回，留下两个事项的证据链 |

**个人记录放哪里：** 按手册第 1 步建立证据区；采用手册内 Ticket A/B 记录格式。报告、截图和教师示例用于对照；个人结论填写实际观察，尚未复验就注明待复验。

## 遇到问题，回到哪个入口

- 看不懂业务规则或判断理由：回到辅导资料的对应案例。
- 不知道在哪输入、缺少文件、命令报错或中途重开窗口：回到实践手册的准备、排错或恢复步骤，先确认原会话与候选。
- 不知道某个脚本能否直接运行：先查手册是否调用它；参考实验与个人交付按手册区分。
- 同一主题有多份 PPT、图或历史记录：按课堂指定版本使用；首次自学以当前辅导资料和实践手册为主。

下载或移动附件时保留本讲目录结构；只拷贝一个 Markdown 文件可能导致配图、Prompt 或脚本路径失效。

## 按需参考：已有实验说明与资料记录

下面保留本讲已有说明，供查询实验机制、证据范围和课件记录。涉及历史实测、页数或同步状态的描述只对应原记录；当前学习顺序以上方导航为准。

本课程的任务是完成一次自举换挡：先建设并独立验收个人工作台 V0，再由 V0 读取 L03 的确认版 Spec，组织 Codex 交付 FlowERP 库存导出。

按以下顺序使用材料：

1. [辅导资料](辅导资料.md)：理解为什么必须先接受 A，才能启动 B。
2. [实践操作手册](实践操作手册.md)：沿一条授权链完成 V0 建设、库存导出和独立复验。
3. [分步 Prompt](prompts/README.md)：需要扩展某一步时按需使用，不必预先通读。
4. [行动卡](行动卡.md)：提交前快速核对遗漏。
5. [controlled-delivery-handoff Skill](skills/controlled-delivery-handoff/SKILL.md)：需要持续协助和扩展交接记录时使用。

参考仓库中的终态、测试和示例记录用于理解目标，不能代替个人建设、独立复验和实际审核。

本讲唯一主线是：**A 建设并独立验收 Workbench V0 → B 由已接受的 V0 交付库存导出 → 独立复验并具名接受或打回。**
