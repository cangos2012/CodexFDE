# L04 提交索引填写提示

按[实践手册](实践操作手册.md)完成 A→A 独立接受→B→B 独立复验。下面字段索引已有四份材料，可在自己的 `lesson-04-submission/handoff.md` 中核对，不重复生成长报告。

- 本人课程编号、实际日期、控制仓库、解释器与 Codex 版本：
- 当前处于 A 还是 B；未完成事项与下一步：

| 手册步骤 | 原有材料 | 索引时核对什么 |
|---|---|---|
| 1～2 | `WB-L04-BOOTSTRAP.md` | 前序成果、V0 实际缺口、增量合同、写集及正反检查 |
| 3～4 | `A-evidence.md` | A 编号、源码版本、原始 Diff、命令、退出码与非执行者的真实接受 |
| 5～6 | `B-evidence.md` | 有效 A、L03 确认版、B 编号、实际候选、Diff、五组检查与 CSV |
| 7 | `handoff.md` | 实际接受／打回、依据、返工位置、剩余风险和迁移判断 |

## A 的可追查对象

- 当前 A 编号、合同、控制源码版本与具名复验者：
- 仅复验、缺写集、失败／超时、越界、待人审的实际结果：
- 源码变化是否使旧接受失效；重新复验的依据：
- 测试替身、建设者自查、真实非交互调用与独立接受分别证明什么：

## B 的可追查对象

- 被采用的 A 版本与 L03 确认版路径、确认记录、SHA256：
- B 编号、候选绝对路径、起点版本、允许写集与实际变化：
- 在同一候选实际执行的命令、报告、退出码与真实 CSV：
- 八列、可用量、多仓位／批次、排序、空集、特殊字符的观察：
- 文件失败故障是否真正触发、异常是否传播、旧文件／半成品与库存流水状态：
- 真实失败／失效、修订后复验与当前未验证项：

## 人的决定与迁移

- A 与 B 的实际接受者、时间、具体对象及决定理由：
- Codex 结束、自动检查与人工接受分别得到什么结果：
- 若仍处于 review 或需要返工，依据哪个状态规则继续：
- 采购申请导出能复用哪些步骤，哪些业务口径必须重问：

没有实际人员接受时保持待审核，不能由模型代签。密钥、环境文件、运行数据库与候选业务目录不作为课程源码提交。

完成本讲手册中的复验、迁移与审核后，再进入下一讲；缺项回本讲续做。
