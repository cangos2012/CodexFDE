# L04 阅读图解设计

使用内置 ImageGen 生成教材插画。全部为教学示意，不代表运行记录或人工验收。原有图片保留在原处，不覆盖。

主线：先区分 A 与 B，再区分控制工作区、客户源码和候选，最后区分执行结束、检查通过与人的决定。

## 图 1：先验收工作台，再用它交付

文件：`01-build-then-deliver.png`

Use case: scientific-educational. 中文成人初学者课程 L04 的教材插画，横向3:2、1536x1024观感，纯白底、大号深蓝中文无衬线文字，清晰蓝橙配色。少文字、宽松留白，精简平面文件/电脑/人员插画。只画指定内容，不堆术语，不画思维导图、复杂网络、机器人、假界面、小字或无标注框。所有中文逐字准确。小角标写‘教学示意’，不是实测截图。 标题‘先验收工作台，再用它交付’。主体左右两块，左块蓝色标题‘A：把工作台搭好’，主体画人在电脑前检查任务记录的简洁插画，旁边3条短语‘能交任务’‘能留记录’‘能组织检查’，左块底部一个有人工签名笔的标签‘非执行者独立复验并接受’。中间只有一条从左向右的箭头，上方写‘A 被接受后’，下方写‘才能开始 B’。右块橙色标题‘B：交付库存导出’，主体画工作台电脑交给Codex执行，产出一个带简化表格的CSV文件，文件上写‘库存 CSV’，电脑上标签‘已接受的工作台’；旁边2条短语‘调用 Codex 实现’‘按 L03 说明检查’，右块底部人工签名笔标签‘再由人接受或打回’。底部整行结论‘A 验收的是工作台，B 验收的是客户功能’。两块不要画重复的嵌套流程，不要让A通过箭头直接指向B已完成，右侧不要预先画代表完成的绿勾。

## 图 2：知道项目在哪，还要知道这次在哪改

文件：`02-candidate-and-scope.png`

Use case: scientific-educational. 中文成人初学者课程 L04 的教材插画，横向3:2、1536x1024观感，纯白底、大号深蓝中文无衬线文字，清晰蓝橙配色。少文字、宽松留白，精简平面文件/电脑/人员插画。只画指定内容，不堆术语，不画思维导图、复杂网络、机器人、假界面、小字或无标注框。所有中文逐字准确。小角标写‘教学示意’，不是实测截图。 标题‘知道项目在哪，还要知道这次在哪改’。三个大型文件夹从左到右，之间用短单向箭头说明关系。左蓝色文件夹标题‘控制工作区’，下面两行‘保存需求和任务记录’‘组织执行与检查’。中间灰色文件夹标题‘独立 FlowERP 仓库’，下面两行‘客户产品源码’‘有自己的运行环境’。右侧橙色文件夹标题‘本次隔离候选’，下面两行‘本次修改发生在这里’‘复验也检查这个版本’。中间到右侧箭头标‘准备本次候选’，左侧到中间箭头标‘登记客户项目’。右侧文件夹内部有一份文件清单简图，三条示意：‘允许的导出实现’、‘允许的命令入口’、‘允许的测试’，这三条用蓝色细边包围并标‘先确认具体文件’，清单之外单独放红色文件标签‘.env：禁止提交’。底部大字‘选对目录 ≠ 可以修改整个目录’，下方较小但清晰‘工作目录决定在哪做，文件清单决定能改什么’。各文件夹关系是职责示意，不能画成全部嵌套在同一个目录，不能把客户源码画到控制工作区内部。

## 图 3：调用结束、检查通过、人工接受是三件事

文件：`03-finished-versus-accepted.png`

Use case: scientific-educational. 中文成人初学者课程 L04 的教材插画，横向3:2、1536x1024观感，纯白底、大号深蓝中文无衬线文字，清晰蓝橙配色。少文字、宽松留白，精简平面文件/电脑/人员插画。只画指定内容，不堆术语，不画思维导图、复杂网络、机器人、假界面、小字或无标注框。所有中文逐字准确。小角标写‘教学示意’，不是实测截图。 标题‘调用结束，不等于交付完成’。从上到下三个独立横排，每排左侧简洁图标，中间具体观察，右侧判断。第一排图标是结束的电脑调用，中间‘Codex 调用结束’下面‘退出码 0’，右侧橙色提示‘还要查：改了什么，结果对不对’。第二排图标是报告和文件差异清单，中间‘业务检查通过’下面‘改动范围也符合约定’，右侧蓝色暂停符号和‘等待人工审核：review’。第三排图标是独立审核者拿笔核对报告，中间‘独立复验同一版本’下面‘具名作出决定’，右侧上下两个短分支标签：绿色‘接受’、橙色‘打回返工’。第一排不能画绿色交付成功，第二排不能写completed。底部结论‘检查证明已检查的要求，人决定是否接受这次交付’。保持从上到下清晰顺序，但不是每排必然自动推进；打回只作为第三排决定之一，不加复杂回环线。


## 最终修订与复核

三张图逐张检查后用于正文。图 1 去掉人物衣服上的 Codex，避免把人误标为 AI；图 2 的文件类别只是示意，正文要求确认具体路径；图 3 去掉暗色背景，确保标题与每层判断清晰。原有总览图保留为选读链接，不删除资产。

### 图 1 修订提示词

精准修改教学图，保留所有中文、左右布局、箭头、文件和人物。只删除右侧橙色衣服上的英文 Codex，衣服保持纯橙色；这个人物代表使用工作台的学生，不是 Codex。其他内容不要改。

### 图 3 修订提示词

修正这张教学图的严重可读性问题。所有背景必须是完全纯白色，删除所有深蓝阴影、光晕、渐变、暗色蒙层和光照效果。保持三个横排的布局、人物、报告图标和全部中文原文不变；所有深蓝标题与正文在纯白背景上清晰可读。标题必须完整清晰为‘调用结束，不等于交付完成’。三个横排中间的文字分别是‘Codex 调用结束’‘退出码 0’；‘业务检查通过’‘改动范围也符合约定’；‘独立复验同一版本’‘具名作出决定’。右侧标签保留浅橙、浅蓝、浅绿实色底，不用光晕。底部原文‘检查证明已检查的要求，人决定是否接受这次交付’。严格平面白底印刷教材风格，零渐变。
