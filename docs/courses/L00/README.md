# L00｜课前准备：装好工具，跑通第一次环境自检

本讲只准备环境。首次学习打开[课前准备手册](L00｜课前准备：装好工具，跑通第一次环境自检.md)，按自己系统对应的命令逐步执行。

## 按这个顺序使用资料

| 顺序 | 打开什么 | 完成标志 |
|---|---|---|
| 1. 建立个人记录 | [L00 空白提交模板](../labs/L00/SUBMISSION.md) | 按手册另存为 `lesson-00-submission/L00-环境自检.md`，保留模板原文件 |
| 2. 安装与自检 | [课前准备手册](L00｜课前准备：装好工具，跑通第一次环境自检.md) | 按八项任务安装工具、建立 `.venv`、打开工作区并记录实际自检结果 |
| 3. 核对与练习 | 同一手册后半部分 | 亲自核对 Codex 提供的文件证据，完成四个小练习，保存个人记录 |

终端用来执行命令，编辑器用来写记录，Codex 对话框用来发送自然语言请求。遇到失败停在当前步骤，记录原错误并按手册排查；不要将示例输出抄成自己的结果。

本目录只有一份课前手册，不需要另找辅导资料、PPT 或 Skill。工具安装包按手册中的来源获取。未完成或尚未确认的项目如实填写。

完成后进入 [L01](../L01/README.md)。返回[课程总入口](../../README.md)。
