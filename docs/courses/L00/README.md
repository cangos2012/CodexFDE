# L00｜课前准备：装好工具，跑通第一次环境自检

**L00 先准备正式实践需要的工具、课程参考仓库和 Python 环境，完成一次只读核验。** 工作台的第一块能力从 L01 的隔离练习区开始建设。

主线是：**装好工具 → 克隆参考仓库 → 创建并安装 `.venv` → 打开课程工作区 → 检查导入与核验文件 → 保存记录 → 进入 L01。** Windows 使用 PowerShell，macOS 使用 zsh，每步只运行自己系统的命令。

## 按这个顺序使用资料

| 顺序 | 打开什么 | 完成标志 |
|---|---|---|
| 1. 顺序准备与核验 | [L00 实践手册](./L00｜课前准备：装好工具，跑通第一次环境自检.md) | 同一参考仓库的 `.venv` 可运行；Codex 引用的至少两个文件已由本人打开核对 |
| 2. 随做随记录 | [L00 空白提交模板](../labs/L00/SUBMISSION.md) | 真实版本、路径、输出、失败和未知项已保存到 `lesson-00-submission/L00-环境自检.md` |
| 3. 交接到正式建设 | [L01 实践手册](../L01/实践操作手册.md#prepare) | 从记录中的参考仓库创建隔离区，重新核对解释器与源码位置 |

参考仓库提供课程材料、准备工具和可对照实现。L00 只确认它能被当前环境正确读取；L01 在隔离区移除本讲增量，再由你监督 Codex 建立需求、测试与实现。参考实现的存在不代表自己的工作台已建成。

终端执行命令，编辑器查看文件和写记录，Codex 对话框接收自然语言任务。遇到失败停在当前步骤，保留原错误，修复后重新检查。Codex 的完成声明不能替代你的现场操作。

想先体验浏览器、Python 和 SQLite 怎样配合，可以完成[选做实验：从 0 开始搭建个人 AI 研发工作台](./从0开始搭建个人AI研发工作台.md)。这份 V0.0 教程与已有实验成果继续保留在独立目录，不计入 L00 通过标准，也不作为 L01 的代码基线。

完成正式 L00 后，带着参考仓库路径、`.venv` 路径和个人记录进入 L01。返回[课程总入口](../../README.md)。
