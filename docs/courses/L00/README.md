# L00｜课前准备：装好工具，跑通第一次环境自检

**本讲从一个没有任何代码的空目录开始，用 Codex 建成可运行的个人 AI 研发工作台基础版 V0.0。** 后面的讲次逐步优化它。

主线是：**看目标架构 → 装好工具 → 建空项目 → 确认需求与结构 → Codex 生成源码 → 启动工作台 → 检查保存与重启 → 留下基础版。** Windows 使用 PowerShell，macOS 使用 zsh，每步只运行自己系统的命令。

## 按这个顺序使用资料

| 顺序 | 打开什么 | 完成标志 |
|---|---|---|
| 1. 准备工具 | [工具准备手册](./L00｜课前准备：装好工具，跑通第一次环境自检.md)第 1 步 | Python、Git、VS Code 与 Codex 可用 |
| 2. 从零建设 | [从 0 开始搭建个人 AI 研发工作台](./从0开始搭建个人AI研发工作台.md) | 先看开头的目标关系与 V0.0 架构图，再从空目录生成程序，亲自走通四项检查 |
| 3. 保存记录与版本 | [L00 空白提交模板](../labs/L00/SUBMISSION.md) | 从第 1 步填写真实记录；四项检查后保存本地 Git 版本 |

L00 不克隆成品工作台、不复制课程源码，也不借用参考仓库的运行环境。教材和模板用于指导；程序由你与 Codex 在新项目中从零建设。

终端执行命令，编辑器查看文件和写记录，Codex 对话框接收自然语言任务。遇到失败停在当前步骤，保留原错误，修复后重新检查。Codex 的完成声明不能替代你的现场操作。

完成后保留 V0.0 源码、已确认的需求和个人记录，作为后续讲次的建设起点。返回[课程总入口](../../README.md)。
