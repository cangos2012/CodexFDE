# L14｜让交付状态在 Web 面板可见

本讲以采购页错误恢复为例，学习状态含义、信息层级、数据新鲜度、失败重试和产物追踪。

先读[辅导资料](辅导资料.md)，再按[实践操作手册](实践操作手册.md)完成观察、个人实现、业务对账和同伴复验。用[行动卡](行动卡.md)查漏，按[提交模板](SUBMISSION.md)整理自己的证据。

需要时使用[分阶段提示词](prompts/README.md)、[页面状态审查 Skill](skills/web-state-review/SKILL.md)及[只读事项对照工具](examples/read_initiative.py)。图解与实操截图随正文学习；制作源保存在教师资料中。

配套资料：[辅导资料](辅导资料.md)、[实践操作手册](实践操作手册.md)，可按需查阅。
