# L14｜按问题查阅的参考说明

首次学习按[实践手册](../实践操作手册.md)推进。本页保留独有机制边界和历史索引，基础案例不重复展开。

2026-10-03 本次整理核对现有材料与所列源码；没有重跑历史实验，也不替学生取得真实执行、人审或迁移证据。

## 1. 请求新鲜度与对象版本

请求序号用于防止旧响应覆盖新视图，对象版本用于核对业务变更与审核依据，二者不能互代。读取失败时要说明旧信息还能否参考、哪些操作须关闭；提交结果未知时先查原对象再决定重试。

工作台事项、Task 和客户采购单不同；状态来源应分别回到真实 API 与持久对象。API/SQLite 一致还不能单独证明浏览器正确。

## 2. 下载与业务产物边界

候选补丁、交付报告和库存 CSV 分别属于不同输出。文件下载成功不能证明任务已经接受，也不能把客户 CSV 当作原 Task 的补丁；下载失败应保留实际响应和缺失项。
