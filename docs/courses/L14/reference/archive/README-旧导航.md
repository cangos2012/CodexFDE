# L14｜让交付状态在 Web 面板可见

## 第一次打开，按这条路线走

本讲支持 Windows PowerShell 与 macOS zsh；先按[实践手册](../../实践操作手册.md)激活环境。工作台、FlowERP、只读核对分别使用各自窗口，新窗口重设解释器和客户路径；恢复时沿用原运行目录。

让人通过工作台查看进展、报告和文件，并到 FlowERP 核对页面修复。

**开始前准备：** 工作台任务与客户页面的真实起点。

| 顺序 | 打开什么 | 现在做什么，做到哪里再继续 |
|---|---|---|
| 1. 看懂本讲任务 | [辅导资料](../../辅导资料.md) | 先读开头的案例或总览，写下本讲要解决的问题；原理随实践回查 |
| 2. 开始操作 | [实践操作手册](../../实践操作手册.md) | 手册第 1～3 步：首次判断、隔离观察、失败与恢复；能指出页面状态来自哪份后端事实 |
| 3. 完成本人实现 | [实践操作手册](../../实践操作手册.md) | 第 4～6 步：实现页面合同，核验业务、报告与下载 |
| 4. 复验与交接 | [行动卡](行动卡.md)及手册末尾 | 第 7 步：同伴复验及迁移 |

**个人记录放哪里：** SUBMISSION.md；保留同一事项的四方对账与验收意见。报告、截图和教师示例用于对照；个人结论填写实际观察，尚未复验就注明待复验。

## 遇到问题，回到哪个入口

- 看不懂业务规则或判断理由：回到辅导资料的对应案例。
- 不知道在哪输入、缺少文件、命令报错或中途重开窗口：回到实践手册的准备、排错或恢复步骤，先确认原会话与候选。
- 不知道某个脚本能否直接运行：先查手册是否调用它；参考实验与个人交付按手册区分。
- 同一主题有多份 PPT、图或历史记录：按课堂指定版本使用；首次自学以当前辅导资料和实践手册为主。

下载或移动附件时保留本讲目录结构；只拷贝一个 Markdown 文件可能导致配图、Prompt 或脚本路径失效。

## 按需参考：已有实验说明与资料记录
