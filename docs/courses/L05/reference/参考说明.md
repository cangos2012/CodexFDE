## 两种红灯用于回答不同问题

第 3 节的副本故意让返回值正确、流水重复，用来证明旧检查没有观察持久化明细。第 5 节正式起点可能因同键重放触发唯一键冲突，验证课程起点与实际修复。两份证据不能交换：前者揭露裁判盲区，后者构成正式执行的红→绿关系。

工程范围也有两种时间边界。准备程序的元数据变化属于候选建立；真实执行者的写集应读取执行器采集的前后变化。独立 Git 实验则专门反证新增、删除、重命名与合法修改是否完整取得，不能仅凭最终 `git diff HEAD` 宣称本轮越界。

## 迁移时保留什么，重新决定什么

迁移到支付回调时保留业务身份、同身份重放、合法新请求、拒绝后状态与真实差异的方法。重新确定金额、账户和资金流水的预期；库存常量与收货类型不成为新业务答案。个人断言需要独立依据，直接调用被测函数生成期望会把缺陷写入裁判。
