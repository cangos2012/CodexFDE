## 先处理会卡住或验错的地方

### 01｜P1：L01 的练习仓库接不上 L04/L05 的标签入口

**证据状态：隔离准备实跑＋源码核对。**

[L01 手册](D:/work/CodexFDE/docs/courses/L01/实践操作手册.md:99)使用 `course-prepare --source working-tree`，让学生进入独立练习仓库。[L04](D:/work/CodexFDE/docs/courses/L04/实践操作手册.md:24)要求一直从该课程练习仓库操作；[L05](D:/work/CodexFDE/docs/courses/L05/实践操作手册.md:540)又要求验证 `course/l05-start`。

[快照实现](D:/work/CodexFDE/workbench/course_snapshot.py:119)只初始化一个新 Git 仓库及快照提交，不带 remote 或课程标签；[执行入口](D:/work/CodexFDE/workbench/course_delivery.py:48)仍要求固定标签。隔离探针中 tag 和 remote 列表为空，L04/L05 的 `baseline_commit=null`、`ready=false`。因此在 L01 快照中照搬 `git fetch origin --tags` 也无法解决。

**修法：**设计一条保留学生 Spec、源码和证据的真实交接路径，统一后续准备与执行所用基线；或者提供经过验证的本地快照执行入口。不能把任意提交命名为缺失标签来冒充课程起点。
