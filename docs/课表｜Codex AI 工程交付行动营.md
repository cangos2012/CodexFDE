## 直播与项目诊所安排

- 环境与 Spec 诊断：处理编码、路径、依赖安装、规则未生效和验收项不可执行等问题。
- Eval 设计评审：检查用例是否验证业务结果，区分阻断项与观察项。
- 多 Agent 设计评审：排查角色重叠、无限循环、共享状态污染与并行写入冲突。
- 成果展示：冷启动演示，展示完整交付链路，并说明一次失败、修订和剩余风险。
